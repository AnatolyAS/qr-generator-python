# QR-Generator-Python

Генератор QR-кодов, написанный на Python с использованием PySide6. Проект представляет собой подробную реализацию спецификации **ISO/IEC 18004:2015** (QR Code Model 2) «с нуля», без использования сторонних библиотек для кодирования.

## Назначение

Проект создан для детального изучения и визуализации алгоритмов, лежащих в основе генерации QR-кодов.

## Архитектура проекта

Проект строго разделен на слои для обеспечения чистоты кода и тестируемости:

*   **`core/` (Бизнес-логика):**
    *   `encoder.py`: Кодирование данных в режимы Numeric, Alphanumeric и Byte, а также поддержка смешанного кодирования (*Mixed Encoding*).
    *   `ecc.py`: Реализация алгоритма коррекции ошибок Рида-Соломона. Работа с полями Галуа $GF(256)$, генерирующими многочленами и расчет байтов коррекции.
    *   `masking.py`: Оценка штрафов для 8 типов масок и выбор оптимальной согласно правилам спецификации.
    *   `matrix_builder.py`: Физическое размещение служебных узоров (*finder*, *alignment*, *timing*), форматной информации и переплетение блоков данных.

*   **`gui/` (Графический интерфейс):**
    *   `window.py`: Основное окно приложения (*QMainWindow*).
    *   `widgets.py`: Кастомные виджеты для отображения матрицы QR-кода и кнопок управления.

*   **`resources/` (Справочные данные):**
    *   `version_tables.py`: Таблицы максимального объема данных, количества блоков и байтов коррекции (на основе Таблиц 2, 4, 5 из спецификации).
    *   `galois_tables.py`: Предрассчитанные таблицы EXP/LOG для полей Галуа (Таблицы 7, 8).

*   **`utils/` (Утилиты):**
    *   `image_utils.py`: Отрисовка матрицы `bool[2D]` в графические форматы PNG и SVG.

## Алгоритм

В основе логики кодирования лежит цикл статей **«QR Code Demystified»** Джейсона Брауна. В данном проекте учтены все нюансы, которые были опущены в оригинале.

Подробное описание этапов генерации (кодирование, добавление служебной информации, разделение на блоки, создание байтов коррекции Рида-Соломона и размещение на холсте) вы можете найти в статье [1](#title1)



## Технологии

*   **Python 3.9+**
*   **PySide6** (LGPL, свободен для коммерческого использования)
*   **Pillow** (для экспорта изображений)

## Запуск

1.  Создайте виртуальное окружение:
    ```bash
    python -m venv venv --upgrade-deps
    source venv/bin/activate  # или .\venv\Scripts\Activate
    ```
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите приложение:
    ```bash
    python main.py
    ```

## Лицензия

LGPL (используется PySide6). Проект для личного и образовательного использования.
